Import CGM export

Paste the full Lingo export each time you receive a new file. The export is cumulative and contains the whole current sensor history, so the safest workflow is to import the complete file again rather than trying to remember the last import time or pasting only the newest rows. The importer will merge all valid data into the active sensor and automatically skip exact duplicates. If the same timestamp appears with a different value, it will be flagged for review rather than silently overwriting the earlier reading.

Do not include the column-title row. The first data row should be the first timestamp, not a header. This importer accepts both comma-separated and tab-separated Lingo exports.

Average daily glucose

2026 Daily Average Glucose
A healthy daily average glucose is usually around 80–120 mg/dL. In general, the lower end of this range aligns with a healthier metabolic state, while averages above ~120 mg/dL suggest poorer glycemic control. HbA1c tracks with the average glucose over time: roughly every increase of ~35 mg/dL in daily average glucose corresponds to about a 1% increase in HbA1c. For example, a daily average near 100 mg/dL is approximately an A1c around 5.1–5.5%, while 120 mg/dL is roughly 5.8–6.0%.
